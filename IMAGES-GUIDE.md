## 📥 Instructions d'Installation

### Étape 1 : Télécharger les images

1. Visitez les sites recommandés (Unsplash ou Pexels)
2. Cherchez les termes indiqués pour chaque image
3. Choisissez des images **haute qualité** (minimum 1920x1080)
4. Téléchargez au format JPG
5. Renommez chaque image avec le nom exact indiqué

### Étape 2 : Placer les images

```bash
# Depuis la racine du projet new-site
cp vos-images-téléchargées/*.jpg public/images/backgrounds/
```

Structure finale :
```
new-site/
└── public/
    └── images/
        └── backgrounds/
            ├── meditation-stones.jpg
            ├── bamboo-forest.jpg
            ├── zen-garden.jpg
            ├── peaceful-nature.jpg
            ├── green-leaves.jpg
            ├── spa-stones.jpg
            └── lotus-flower.jpg
```

### Étape 3 : Vérifier

Lancez le serveur de développement :
```bash
npm run dev
```

Visitez chaque page pour vérifier que les images s'affichent correctement.

## 🎨 Critères de Sélection

Pour un rendu optimal, choisissez des images qui :

✅ Ont une **résolution minimum de 1920x1080** (Full HD)
✅ Ont des **tons verts/naturels** qui s'harmonisent avec la palette du site
✅ Ne sont **pas trop chargées** (éviter trop de détails)
✅ Ont une **zone centrale dégagée** pour le texte
✅ Ont une **ambiance zen et apaisante**
✅ Sont en **format paysage** (horizontal)

## ⚡ Optimisation des Images (Optionnel)

Pour de meilleures performances, vous pouvez optimiser les images :

### En ligne
- [TinyPNG](https://tinypng.com/) - Compression sans perte de qualité
- [Squoosh](https://squoosh.app/) - Outil Google de compression

### Recommandations
- **Format :** JPG (meilleur pour les photos)
- **Taille :** 1920x1080 ou 1920x1200
- **Poids :** Idéalement < 500 KB par image
